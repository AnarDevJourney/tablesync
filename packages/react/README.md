# tablesync

[![npm](https://img.shields.io/npm/v/tablesync.svg)](https://www.npmjs.com/package/tablesync)

React + Ant Design data table that saves each user's columns, widths, pins, density and view on your server.

```bash
npm install tablesync
```

This folder is the source of the [`tablesync`](https://www.npmjs.com/package/tablesync) npm package. Docs and a live demo: [tablesyncpackage.netlify.app](https://tablesyncpackage.netlify.app).

Backend: [`tablesync-nest`](https://www.npmjs.com/package/tablesync-nest) ([source](../nest)).
